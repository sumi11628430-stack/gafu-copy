# 画風コピペシート

写真や絵を1枚、好きな画風に描き直すためのChatGPT用プロンプトを、選ぶだけで作れるページです。

- 1枚モード：① 仕上がりの雰囲気（例78）／② 画像内の文字／③ 縦横比／④ 避けること を選んで、全文をコピーできます
- 2枚モード：1枚目の人物や動物を、2枚目の写真に差し込む・差し替えるプロンプトを作れます
- もしもシリーズ：「もしもあなたが〇〇だったら」を選ぶと、写真の人・ペット・ぬいぐるみ・物などがその姿に生まれ変わるプロンプトが出ます（選択肢48。だれでも使えるのは、10のmdの「公開するもしも」に書いた物だけで、ほかは鍵つき）
- 入力や選択はページの中だけで使われ、どこにも送信されません

## ページ

- `/`：トップ（使い方・画風の見本・2枚を合わせる・もしもの作例）。元は `src/top.html`
- `/sheet/`：プロンプトを作るページ。元は `src/template.html`。`?mode=2` で2枚モード、`?mode=3` でもしもシリーズ、`?mode=3&m=番号` でそのもしもを開いた状態（鍵つきの物は開かず、案内だけ出る）、`?s=画風の名前`（例：`?s=ステンドグラス`）でその画風を選んだ状態で開く。`?s=数字` は、2026-10-07に画風の番号を振り直す前の番号で、出回っているリンクのために残してある（画面の番号とは別。行き先は `tools/style_table.json` の「リンクの番号」）
- `images/moshi/`：トップのもしもの作例（AIで作った架空の人物・ペットの写真を、このページのプロンプトで変身させたもの）

## 更新のしかた

1. プロンプトの元になるmdファイルを直す
   - 画風モード・2枚モード：`08_好きな画像を好きな画風にプロンプト.md`
   - もしもシリーズ：`10_もしもシリーズプロンプト.md`（08と同じフォルダに置く）
2. `node tools/build.js <08のmdファイルのパス>` で `index.html`（トップ）と `sheet/index.html`（道具の画面）を作り直す（10のmdは08と同じフォルダから読む。別の場所なら2つ目の引数で渡す）
3. カード画像を作り直すときは `python tools/make_ogp.py`（Playwrightとインストール済みのChromeを使用）

公開先のURLが変わったときは、`tools/build.js` の `SITE_URL` を直してから作り直してください。

## 08のmdの画風の一覧を手で直すときの決まり

書き違いがあると、ビルドはエラーで止まります（壊れたページは書き出しません）。

- 画風の行は `番号. 印名前（説明）`。番号は、系統をまたいで上から順に1から続けて振る（途中に足したら、後ろの番号を振り直す）
- 系統の見出しは `■系統名`。その系統の画風が全部「素材でできた作品を撮った写真」として作る物なら、見出しの終わりに `〔素材〕`、全部「写真として撮り直す」物なら `〔写真〕` を付ける（印は画面には出ない）
- 画風の名前（`（` より前）は重ねない。名前を変える・消すときは、`tools/style_table.json` の「リンクの番号」の名前も直す（番号つきリンクの行き先を、名前で持っているため）
- 素材・写真の画風を足す・消す・名前を変えるときは、`tools/style_table.json` の「素材」「写真」も直す

## 10のmd（もしもシリーズ）を手で直すときの決まり

書き違いがあると、ビルドは行番号つきのエラーで止まります（壊れたページは書き出しません）。

- 部品は1行1部品（`部品名：中身`）。中身が2行以上のときは、2行目以降を `・` で始める（字下げや `- ` は使えない）
- 選択肢の行は `番号. 印言葉｜型｜仕上がり｜向き｜本人｜テーマ｜AIが考える文字｜華やかさ｜似せ方｜縦横比｜季節の月｜絵柄｜守り｜カメラ：説明`。区切りは全角の `｜`、説明の前は全角の `：`。言葉や項目の中に `：` を入れない。印（★・◆）は `番号. ` の直後にスペースなしで付ける
- 向きは `なんでも` か `人以外`（写真の種類で選択肢を隠すことはしない。人以外は「人以外向け」の印が付き、人だけの写真では断る）
- 守りが `作品` の選択肢（42）は、「作品キャラの核」の文面で組み立てる（守りの行・除外の行は入らない。カメラワーク・作品のロゴ・縦横比・自分の言葉・避けることは、選んだときだけ行が足される）
- カメラは `固定`（撮り方そのものが中身の選択肢）か、「もしものカメラワーク」の一覧の名前（最初の状態。`おまかせ` はプロンプトに何も足さない）。おまかせ以外を最初から選ぶ選択肢は、似せ方を `のびのび` にする
- 一言・注意の行は、全角スペース1つで字下げして `　一言：` `　注意：` と書く
- 季節の月は半角数字と半角カンマ（例：`12,1`）。出さないときは全角の `－`
- 縦横比は③の `（` より前と同じ言葉（例：`縦長 2:3`）か `おまかせ`
- 注意書きは `- ` で始まる1行が1項目（折り返さない）。`[最初] ` を付けた3行が一覧の下にいつも出る
- 番号は系統をまたいで1から続けて振る。途中に足すと後ろの番号がずれ、トップの作例リンク（`src/top.html` の `m=` と `data-moshi`）や共有済みのURLもずれる。新しい選択肢はなるべく最後に足す（作例リンクのずれはビルドで止まる）
- `## 公開するもしも` の節に言葉を1行ずつ書いた選択肢だけが、だれでも使える。書いていない選択肢は「鍵つき」で、ページには一覧に出す物（名前・印・一言など）だけが入り、説明・注意と、その選択肢だけが使う部品・核は入らない（押しても開かない。`m=番号` のリンクでも開かない）。全部を公開にするときは、枠の中を `全部` の1行だけにする（節や枠が無いと、まちがって全部が公開にならないように、ビルドは止まる）
- `## 作品キャラの画面の文` は、守りが `作品` の選択肢の画面に出す文（セーフティON・OFFの説明と、文字の名前）。その選択肢を公開するときだけ、ページに入る（作品のロゴ・セーフティの欄の名前と、ロゴの注意の文は、ページの元 `src/template.html` にあり、いつもページに入る。プロンプトの中身ではない）
- カード画像（`ogp.png`）の「もしも ○種」は自動では変わらない。公開する数を変えたら、`tools/make_ogp.py` の文字を直して作り直す
